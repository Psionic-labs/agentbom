# Security

## Report a vulnerability in agentbom

Email [hello@psioniclabs.tech](mailto:hello@psioniclabs.tech).

Include the command you ran, the file that produced the result, and the installed version from `python -c "import importlib.metadata; print(importlib.metadata.version('contextlock'))"`. Leave secret values out of the message.

Do not open a public GitHub issue for a vulnerability in agentbom.

## Findings in other repositories

A finding agentbom reports in someone else's repository follows [the vulnerability disclosure policy](docs/agentbom%20Vulnerability%20Disclosure%20Policy.md). This file is only the contact for agentbom itself.
